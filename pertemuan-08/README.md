# Pertemuan-08 ☕ KEDAI KOPI NIZAR

1. Deskripsi Website

Kedai Kopi Nizar merupakan website sederhana yang dibuat untuk memperkenalkan kedai kopi dengan berbagai pilihan menu minuman, informasi kedai, dan fasilitas pemesanan secara online.

Website ini dibuat sebagai tugas UTS mata kuliah Pemrograman Web Dasar.

2. Tujuan Pembuatan

- Memperkenalkan Kedai Kopi Nizar kepada masyarakat.
- Menampilkan berbagai pilihan menu kopi.
- Memberikan informasi mengenai produk dan layanan kedai.
- Memudahkan pelanggan melakukan pemesanan.
- Menerapkan ilmu HTML, CSS, PHP, dan JavaScript dalam pembuatan website.

3. Teknologi yang Digunakan

- HTML: Membuat struktur halaman website.
- CSS: Mengatur tampilan dan desain website.
- PHP: Mengelola halaman dan proses formulir.
- JavaScript: Membuat website lebih interaktif.
- Visual Studio Code: Aplikasi untuk menulis dan mengedit kode.

4. Fitur Website

1. Halaman Home: Menampilkan halaman utama Kedai Kopi Nizar.
2. Tentang Kami: Menampilkan informasi dan profil kedai.
3. Daftar Menu: Menampilkan berbagai pilihan minuman kopi.
4. Form Pemesanan: Berisi nama lengkap, nomor Antrian, nomor telepon, tanggal pemesanan, pilihan menu, dan jumlah pesanan.
5. Footer: Menampilkan informasi hak cipta dan identitas pembuat website.

6. Langkah-Langkah Pembuatan

1. Membuat folder project Kedai Kopi Nizar.
2. Membuat file index.php sebagai halaman utama.
3. Membuat file style.css untuk mengatur desain website.
4. Menambahkan gambar produk kopi ke dalam folder img.
5. Membuat halaman menu untuk menampilkan produk kopi.
6. Membuat formulir pemesanan pelanggan.
7. Menambahkan jumlah pesanan.
8. Mengatur tampilan website agar rapi dan mudah digunakan.
9. Menjalankan website melalui localhost.
10. Melakukan pengecekan terhadap seluruh halaman dan fitur website.
